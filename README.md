# 占い・スピリチュアル SNSアカウント 投稿文集

占いとスピリチュアルに特化したSNSアカウントの投稿文・コンテンツ設計をまとめたリポジトリです。

## ファイル構成

```
posts/
├── tarot.md            # タロット占い関連投稿文
├── astrology.md        # 星占い・占星術・月の満ち欠け関連投稿文
├── numerology.md       # 数秘術・エンジェルナンバー関連投稿文
├── crystal_spiritual.md # パワーストーン・チャクラ・引き寄せ関連投稿文
└── content_calendar.md  # 投稿カレンダー・コンテンツ戦略
```

## 使い方

各ファイルの投稿文をSNS（X・Instagram・Threads等）にコピーして投稿してください。
ハッシュタグはプラットフォームに合わせて調整してください。

- **X（旧Twitter）：** ハッシュタグは3〜5個に絞る
- **Instagram：** ハッシュタグは10〜15個使う
- **Threads：** ハッシュタグは少なめ（3個程度）

## 投稿スケジュール

`content_calendar.md` に週間・月間の投稿カレンダーとハッシュタグ戦略をまとめています。
