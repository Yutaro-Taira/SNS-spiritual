# アカウント名候補 10選

## 選定コンセプト
- 一目で「スピリチュアル・占い」とわかる
- 日本語として美しく、声に出しても語感がいい
- 英語・日本語・造語をミックスしてバリエーションを持たせた
- X（旧Twitter）の表示名・ユーザーID両方を想定

## 各候補の詳細・おすすめポイント

### 1. 月詠み（つきよみ）
- X ID案：`@tsukiyomi_tarot` / `@tsukiyomi_uranai`
- 強み：日本神話のツクヨミと直結、権威感と神秘感が自然に生まれる
- 向き：和テイストのビジュアル・落ち着いた世界観にしたい場合

### 2. 星紡ぎ（ほしつむぎ）
- X ID案：`@hoshi_tsumugi` / `@hoshistsumugi`
- 強み：「紡ぐ」という言葉に手仕事・丁寧さが宿り、親しみやすい
- 向き：優しく温かい雰囲気のアカウントにしたい場合

### 3. Luna Veil（ルナヴェイル）
- X ID案：`@luna_veil_` / `@lunaveil_oracle`
- 強み：英語なのでSEOにも強く、ブランド展開がしやすい
- 向き：スタイリッシュ・洗練されたビジュアルを目指す場合

### 4. 幽星（かすみほし）
- X ID案：`@kasumiboshi` / `@kasumi_hoshi`
- 強み：読み方を知ると「かわいい」と感じてもらえる。記憶に残る
- 向き：淡く幻想的なパステルカラーの世界観

### 5. Aura Oracle（オーラオラクル）
- X ID案：`@aura_oracle_jp` / `@aura_oracle`
- 強み：「オーラを読む人」という能力が一発でわかる。機能的な名前
- 向き：チャクラ・エネルギーワーク・ヒーリング寄りのコンテンツ

### 6. 宵闇の巫女（よいやみのみこ）
- X ID案：`@yoiyami_miko` / `@yoiyami_oracle`
- 強み：ダークで神秘的。「本物感」「格式」が出る重厚な名前
- 向き：しっかりした世界観・ファン層が深くつく傾向

### 7. Celestia（セレスティア）
- X ID案：`@celestia_oracle` / `@celestia_tarot`
- 強み：ゲーム・アニメ好き層にも響く。天上界のイメージが強い
- 向き：キラキラした星・宇宙・天使系のビジュアル

### 8. 紫煙（しえん）
- X ID案：`@shien_tarot` / `@shien_spiritual`
- 強み：漢字2文字でインパクト大。大人っぽく、ミステリアス
- 向き：大人向け・落ち着いた世界観・深みのあるコンテンツ

### 9. 星詠み師リラ
- X ID案：`@hoshiyomishi_lira` / `@lira_tarot`
- 強み：「師」という字でプロ感、「リラ」でキャラクター感が生まれる
- 向き：占い師としての人格・キャラクターを前面に出したい場合

### 10. Mystic Tsuki（ミスティックツキ）
- X ID案：`@mystic_tsuki` / `@mystic_tsuki_jp`
- 強み：英語話者にも発音しやすい日本語（Tsuki=月）が入ったハイブリッド
- 向き：グローバル展開・英語でも発信したい場合

## 選び方のヒント

**和テイストで神秘的に →** 月詠み・宵闇の巫女・紫煙
**優しく親しみやすく →** 星紡ぎ・星詠み師リラ
**スタイリッシュ・ブランド感 →** Luna Veil・Celestia・Mystic Tsuki
**能力・機能が伝わる →** Aura Oracle・幽星
