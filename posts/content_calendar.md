# SNS投稿カレンダー・コンテンツ設計

## アカウントコンセプト

**テーマ：** 占いとスピリチュアルの力で、毎日をもっと自分らしく生きる
**ターゲット：** 20〜40代の女性（占いに興味がある・スピリチュアルに関心がある）
**投稿頻度：** 1日1〜2投稿（Xなら多め、Instagramは1日1投稿）

---

## 週間投稿テンプレート

| 曜日 | テーマ | 内容例 |
|------|--------|--------|
| 月曜日 | 週間タロット | 今週のカードと運勢メッセージ |
| 火曜日 | 星座・惑星情報 | 今日の月の星座・惑星の動き |
| 水曜日 | 数秘術 | 今日の数字・数秘解説 |
| 木曜日 | パワーストーン | 石の紹介・使い方・浄化法 |
| 金曜日 | 恋愛占い | タロットor星座での恋愛メッセージ |
| 土曜日 | スピリチュアルTips | 引き寄せ・チャクラ・ヒーリング |
| 日曜日 | 来週への準備 | 月の満ち欠け・新月満月のワーク |

## 月間コンテンツの柱

### 1. 教育コンテンツ（30%）
- タロットカード解説シリーズ（大アルカナ22枚）
- 星座・惑星の基礎知識
- 数秘術の計算方法と意味
- パワーストーン図鑑

### 2. 運勢・予言コンテンツ（40%）
- 今日の運勢（タロット一枚引き）
- 週間星座別メッセージ
- 月の満ち欠けと開運アドバイス
- 新月・満月のワーク

### 3. エンゲージメントコンテンツ（20%）
- 「あなたはどのタイプ？」診断
- 生年月日から生命数チェック
- 星座あるある
- コメントで答えてもらう参加型投稿

### 4. ライフスタイルコンテンツ（10%）
- 占い師の日常
- おすすめの本・アイテム紹介
- スピリチュアルな体験談

## エンゲージメントを高めるコツ

1. **質問で終わる投稿を増やす**
   「あなたはどのタイプでしたか？コメントで教えてね」

2. **保存されやすいコンテンツを作る**
   「保存して見返してね」と促す情報量の多い投稿

3. **シリーズ化でフォロー促進**
   「全12星座解説シリーズ、フォローして待っていてね」

4. **タイムリーなコンテンツ**
   新月・満月・水星逆行・季節の変わり目に合わせた投稿

5. **共感を呼ぶコンテンツ**
   「わかる！」「当てはまってる！」と思ってもらえる星座・数字あるある

## 投稿文のトーン・ルール

### やること
- 温かく、寄り添うような語り口
- 「あなた」を主語にした表現
- 希望を与える前向きなメッセージ
- 絵文字を効果的に使う（多すぎない）
- 改行を多用して読みやすく

### やらないこと
- 断定的な「必ず〜になる」という表現
- 不安を煽る表現（「このままでは危ない」など）
- 高額商品・有料鑑定への過度な誘導
- 他の占い師・アカウントの批判

## 投稿のフォーマット例

```
【タイトル行】絵文字 + キャッチーな見出し

【リード文】
共感を呼ぶ一文や問いかけ

【本文】
・ポイントを箇条書きや記号で整理
・改行を多用
・絵文字でリズムをつける

【締め文】
行動を促す一文（コメント・いいね・保存）

【ハッシュタグ】
#スピリチュアル #タロット... （5〜15個）
```
